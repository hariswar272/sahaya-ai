# Code of Conduct

Sahaya AI exists to help people in distress. Everyone contributing to it — in code, issues, reviews or community channels — is expected to:

- Be respectful and patient; many contributors and users are not native English speakers.
- Keep the people we serve in mind: never add dark patterns, data collection or features that could put a caller at risk.
- Give and accept feedback constructively, and assume good intent.
- Report unacceptable behaviour privately to the maintainer listed on the GitHub profile.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1.
