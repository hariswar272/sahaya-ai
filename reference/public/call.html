How it works

1. Sarvam speech-to-text turns Telugu speech into text.
2. The AI model pulls out the facts: location, people, water level, vulnerable people, medical needs.
3. Fixed rules set the priority, so every decision can be explained.
4. Critical cases go straight to the nearest rescue team. The caller hears replies in natural Telugu.
